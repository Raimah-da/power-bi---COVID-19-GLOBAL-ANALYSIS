# power-bi---COVID-19-GLOBAL-ANALYSIS🌍🌍
This repository contains a detailed multipage power bi report designed to analyse and visualize global COVID 19 data.
this project was executed to demonstrate my power bi skills,which includes Data Modelling, creation of custom measure (KPIs), reporting and correlation analysis.
This report followed a narrative accross four pages, moving from summary to detailed analysis of demographic,policy, and trends.

## KEY RESEARCH QUESTIONS REGARDING THE PANDEMIC'S IMPACT AND RESPONSE:
1 DEMOGRAPHIC DRIVERS ( correlation between country's median age , total deaths and cases)
2 POLICY EFFECTIVENESS ( correlation between stringency index and reproduction rate to evaluate the government measures)
3 GEOGRAPHIC TRENDS ( cases accross countries and continents)


This report used the **compact covid-19 dataset** published by **our world in data**

TOOLs USED:
Power Bi
